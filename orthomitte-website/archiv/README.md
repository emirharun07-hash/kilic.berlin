# Archiv – Originalinhalte der Wix-Website

Dieser Ordner wird **nicht** veröffentlicht. Er dient als Nachweis und Fundus.

`wix-original/` enthält für **jede** der 82 Seiten der bisherigen Website
(www.orthopaedische-praxis-mitte.de, Stand 28.10.2026) eine automatisch erzeugte Markdown-Fassung:

- Kopfkommentar: alte URL, Seitentitel, Meta-Description, H1, verwendete Bilder, externe Links
- darunter der Textinhalt der Seite (inklusive aufgeklappter Akkordeon-/FAQ-Inhalte)

Dateiname = alter URL-Pfad (`/` → `__`, z. B. `leistungen-2__eiseninfusion.md`).

Verwendung:
- Seiten, die per 301 weitergeleitet wurden (z. B. ältere `-2`-Fassungen, Corona-Hinweise,
  ehemalige Teammitglieder), können von hier jederzeit wiederhergestellt werden.
- Bei Rückfragen „Was stand früher auf Seite X?“ hier nachsehen.

Hinweis: Die Konvertierung ist automatisch; Listen/Überschriften können vom Original abweichen.
Maßgeblich für die neue Website sind die redigierten Dateien unter `src/content/`.
